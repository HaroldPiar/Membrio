Nombre del Proyecto: Membrio (o SocioBase)
Línea de Investigación / Dominio: Desarrollo de Software / Sistemas SaaS (Software as a Service) Multi-tenant
Descripción General del Proyecto
Membrio es una plataforma de software en la nube diseñada para centralizar la gestión de datos de personal/afiliados y automatizar el seguimiento del ciclo de vida de cobro en entidades que operan bajo modelos de pago recurrente (clubes deportivos, academias académicas, centros culturales y organizaciones con suscripciones presenciales).
El proyecto aborda la problemática común de la dispersión de información y la gestión manual de cobranza en hojas de cálculo tradicionales. La solución integra una base de datos relacional para el control de perfiles, un motor de estados de pago automatizado (Al día, Por vencer, En mora) y un tablero de analítica visual que permite monitorear el flujo de ingresos recurrentes y la cartera pendiente en tiempo real.
Objetivos del Proyecto
 * Objetivo General: Desarrollar un sistema de información web para la gestión centralizada de miembros y el control automatizado de mensualidades periódicas en pequeñas y medianas organizaciones de servicio.
 * Objetivos Específicos:
   * Diseñar una arquitectura de base de datos eficiente para gestionar perfiles de usuarios, planes de suscripción y registros financieros.
   * Implementar un módulo de lógica de negocio para la categorización e historial de estados de pago de cada afiliado.
   * Construir un panel de control (dashboard) intuitivo que consolide métricas de recaudo y alerta sobre estados de morosidad.
   * Validar la aplicabilidad del sistema mediante pruebas de usuario en escenarios reales de clubes y academias.
